# Automa-o--Python--API--WordPress
Automação de serviços utlizando API do Wordpress.
- Upar vários post de uma só vez.
- Cria post com titulos personalizados com TAG SEO
- Cria páginas
- Renomeia Post
- Upload de imagens


# Basta Clonar o projeto e baixar as libs python
- Para utlizar:
git clone https://projeto.com.br
instale as libs
Crie uma API Key do Wordpress
insira as informações do site, nome de usuário e a chave no script config.py e depois execute. 
para testar basta executar o script test_api.py
